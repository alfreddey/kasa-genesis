# Contributing

Thank you for helping Kasa Genesis read stories aloud in Ghanaian languages.

## Stories and translations

Writers, translators and reviewers do not need to code. Start with the [story and spelling guide](docs/content-guide.md): it explains the story fields, how to submit a story (a GitHub issue form or a pull request), how to spell and type each language, what you may submit, and the native-speaker review checklist.

## Code

Read [AGENTS.md](AGENTS.md) for the code map and commands. In short: `make setup`, `make test`, then open a small pull request that references the issue it closes.
